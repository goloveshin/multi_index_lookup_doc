# multi_index_lookup_doc

Documentation for **multi_index_lookup**, a small header-only wrapper around [Boost.MultiIndex](https://www.boost.org/doc/libs/release/libs/multi_index/doc/index.html) that adds lookup by index tag.

The library: <https://github.com/goloveshin/multi_index_lookup>

## Build the site locally

The pages are in `source/`, the configuration is `mkdocs.yml`.

```text
pip install mkdocs
mkdocs serve
```

Open <http://127.0.0.1:8000/>. `mkdocs build` writes the static site to `docs/`.
